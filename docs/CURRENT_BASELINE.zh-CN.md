# 当前工程基线

工作区版本为 AICore `0.4.0`，Rust 基线为 1.75。V4 缺陷修复曾使原有架构通过代码工程门槛；之后针对更广的 [destination](../destination.zh-CN.md) 继续完成了代码、模拟层与有边界的原生探测。代码检查通过并不等于 destination 产品已通过平台验收。

## 已实现的边界

- 契约区分实际成功、不支持、跳过、失败和 NoOp。可能改变状态的绑定必须经过策略验证；执行后读回、回滚和 SafeMode 保留真实失败语义。
- 连续运行的模型模式和平台模式分离慢侧准备与快侧消费。模拟平台使用采集的样本和内存执行；原生适配器运行时探测能力，不捏造缺失读数。
- L0/L1/L2 任务链路、应用身份检查、版本协商 IPC、固定信任策略与类型化的默认拒绝插件能力绑定已按各自文档范围接入。
- 个人记忆须用户选择加入并遵守保留期；观测反馈、本地 JSON/ONNX 推理及可配置 Ollama 意图提供者均已有代码路径。模型和模拟结果与真实设备效果严格分开。
- 当前桌面验证记录包含工作区编译、Clippy、格式检查、前一轮未过滤的 730 项测试，以及模型、模拟层和明确限定范围的原生探测。本轮仅重跑不涉及真实控制的检查。

[验证报告](quality/DESTINATION_VERIFICATION_REPORT.zh-CN.md)保存已完成证据与恢复记录；独立的[待验收测试](quality/OUTSTANDING_TESTS.zh-CN.md)集中记录尚未完成的验收及原因。历史 V3.2/V4 报告仍作为带日期的证据保留，不替代当前清单。
