# Project Glossary

| Term | Definition |
|---|---|
| Computer State | Unified real-time system state |
| Context | Current user/application/task context |
| Workload | Abstract classification of computing activity |
| Policy | System resource policy |
| Validator | Checks policy validity, safety, capability, and conflicts |
| Executor | Applies validated operations |
| Adapter | Black-box boundary for OS, hardware, or runtime differences |
| Tier | Application compatibility path |
| L0 | Legacy / zero-integration |
| L1 | AICore-aware optional integration |
| L2 | Native AICore integration |
| Slow Loop | AI, prediction, and planning loop |
| Fast Loop | Bounded validation and control-execution loop |
| Runtime | Model, hardware, or OS execution provider |
| Control Plane | Decision-making layer |
| Data Plane | Collection, event, and presentation layers |
