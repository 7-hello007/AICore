# Project Glossary

| Term | Definition |
|---|---|
| Computer State | 统一实时系统状态 |
| Context | 当前用户/应用/任务上下文 |
| Workload | 对计算行为的抽象分类 |
| Policy | 系统资源策略 |
| Validator | 策略合法性/安全/能力验证器 |
| Executor | 具体执行层 |
| Adapter | OS/HW/Runtime 黑盒适配器 |
| Tier | 应用兼容路径 |
| L0 | Legacy / zero-integration |
| L1 | AICore-aware optional integration |
| L2 | Native AICore integration |
| Slow Loop | AI/预测/规划环 |
| Fast Loop | 确定性控制执行环 |
| Runtime | 模型/硬件/OS execution runtime |
| Control Plane | 决策层 |
| Data Plane | 数据采集、事件、展示层 |
