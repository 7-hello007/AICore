# 项目术语表

| 术语 | 定义 |
|---|---|
| 计算机状态 | 统一的实时系统状态 |
| 上下文 | 当前用户、应用和任务的上下文 |
| 工作负载 | 对计算行为的抽象分类 |
| 策略 | 系统资源策略 |
| 校验器 | 校验策略合法性、安全性和能力的组件 |
| 执行器 | 具体执行层 |
| 适配器 | 操作系统、硬件和运行时的隔离适配层 |
| 层级 | 应用兼容路径 |
| L0 | 无需应用改造的传统应用接入 |
| L1 | 应用可选择声明任务信息的接入方式 |
| L2 | AICore 原生接口接入方式 |
| 慢环 | AI、预测与规划环 |
| 快环 | 确定性控制执行环 |
| 运行时 | 模型、硬件或操作系统执行环境 |
| 控制平面 | 决策层 |
| 数据平面 | 数据采集、事件与展示层 |
