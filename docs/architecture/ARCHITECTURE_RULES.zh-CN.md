# 架构规则

| 规则 | 要求 |
|---|---|
| R-01 | 核心层不依赖具体平台 |
| R-02 | 核心层不依赖用户界面 |
| R-03 | 核心层不依赖具体 AI 模型 |
| R-04 | 兼容层级之间不互相依赖 |
| R-05 | 适配器只实现接口，不承载业务决策 |
| R-06 | AI 不直接执行系统操作 |
| R-07 | 所有策略必须经过校验器 |
| R-08 | 所有系统控制必须经过执行器 |
| R-09 | 所有跨模块状态都通过契约、事件或数据传输对象传递 |
| R-10 | 新功能优先增加模块或插件，而不是修改核心层 |
| R-11 | 运行时失败必须可回退 |
| R-12 | 删除任一层级或插件不应破坏其他层级或插件 |
