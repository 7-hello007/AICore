# API 设计

## API 类别

| 类型 | 用途 |
|---|---|
| 公开 API | 外部应用与命令行工具 |
| 内部 API | 核心层与运行时内部模块 |
| 平台契约 | Windows 与 Linux 适配器 |
| AI 运行时契约 | 模型与推理后端 |
| 层级契约 | L0/L1/L2 接入 |
| 插件 API | 动态加载的插件 |

## 版本规则

- 向后兼容的新增内容递增次版本号。
- 向后不兼容的变更递增主版本号。
- 废弃的 API 必须提供迁移说明。
- 内部改动必须保持稳定的公开 API。
