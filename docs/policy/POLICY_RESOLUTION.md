# Policy Resolution

Default priority for conflict resolution:

```text
Safety
> Explicit User Intent
> Security / Privacy
> Interactive Latency
> Deadline
> Performance
> Energy
> Background Optimization
```

Any policy combination must produce an explanatory description:

- input policies
- conflict set
- chosen winner
- reason
- validator result
