# Benchmarking

Set a baseline and a regression budget.

Core indicators:

- CPU overhead
- memory overhead
- decision latency
- execution latency
- telemetry latency
- AI inference latency
- dashboard overhead
- energy/power effect
- task latency / throughput

Benchmark data must identify the platform, hardware, configuration, number of ticks, and version.
