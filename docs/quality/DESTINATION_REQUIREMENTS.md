## Validation boundary for this task

The requested `simulated-platform` crate is verification infrastructure, not
a new destination product capability. It uses a real read-only Linux/WSL
capture and exercises the existing Platform Mode interfaces in memory. Its
passing tests narrow integration risk for D-03/D-05/D-12 but do not close
hardware, effect or Windows native acceptance gaps.

Current authorization permits read-only native telemetry and capability tests and isolated real workloads, but no installer execution. Any operation modifying host configuration (including platform process affinity/priority, device power or service state) requires a separate request before execution. Filtered workspace results must be reported as filtered. Native Windows pipe and hardware validation remain separate acceptance evidence.
