## Validation boundary for this task

Only Model Mode, mocks and isolated tests may run. Existing tests that directly call platform process/power/hardware controllers or generate real workloads must remain in the repository and are reserved for the later real-machine stage; a filtered test run must be reported as filtered, never as the complete suite. No system package or service installation is part of this task.
