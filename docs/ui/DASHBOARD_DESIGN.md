# Dashboard Design

目标：现代、简洁、低噪声、信息层级明确。

## 视觉原则

| 原则 | 要求 |
|---|---|
| Hierarchy | 首屏只突出系统状态与 AI Decision |
| Density | 高信息密度但不堆文字 |
| Motion | 仅用于实时变化，不做装饰性动画 |
| Color | 中性深色底 + 少量语义色 |
| Typography | 高可读无衬线 + 等宽数字 |
| Responsive | Desktop / Tablet / Narrow 支持 |
| Accessibility | 状态不能只通过颜色表达 |

## 页面结构

1. Global Status
2. Resource Overview
3. Current Context
4. Active Policy
5. Runtime / Tier / Plugin Health
6. Historical Trend
7. Event Timeline
