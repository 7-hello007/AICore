# 仪表盘设计

目标：现代、简洁、低噪声、信息层级明确。

## 视觉原则

| 原则 | 要求 |
|---|---|
| 层级 | 首屏只突出系统状态与 AI 决策 |
| 密度 | 高信息密度但不堆砌文字 |
| 动效 | 仅用于实时变化，不做装饰性动画 |
| 色彩 | 中性深色底色加少量语义色 |
| 排版 | 高可读性的无衬线字体与等宽数字 |
| 自适应 | 支持桌面、平板与窄屏 |
| 无障碍 | 状态不能只通过颜色表达 |

## 页面结构

1. 全局状态
2. 资源概览
3. 当前上下文
4. 生效策略
5. 运行时、层级与插件健康状态
6. 历史趋势
7. 事件时间线
